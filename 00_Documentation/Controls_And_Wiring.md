# 操作与报警接线

本包是点按旋钮切主题的GitHub发布版。

| 状态／输入 | 功能 |
|---|---|
| 菜单关闭，旋钮点按 | 切换到下一主题 |
| 菜单关闭，旋钮转动 | 切换当前主题图片 |
| 菜单关闭、100%，摇杆左右 | 切换当前主题图片 |
| 菜单关闭、100%，摇杆上下 | 不切换主题 |
| 菜单关闭、150%或200%，摇杆方向 | 平移图片 |
| 摇杆按下／SW0 | 按原菜单逻辑打开或关闭菜单；报警未消音时首次按下摇杆只消音 |
| 菜单内摇杆上下 | 选择项目；保留原有上下连选逻辑 |
| 菜单内摇杆右推／旋钮点按 | 进入或确认；数值编辑保持原逻辑 |
| 菜单内摇杆左推 | 返回 |
| KEY4 | 音乐暂停／继续 |

离位报警：VCC接J1.29的3.3V，GND接J1.30，DO接J1.24（FPGA J16）。磁铁在位为低电平，离位为高电平。蜂鸣器使用板载H11低有效支路；硬件开关按实际板卡丝印选通。模块DO应为3.3V电平。

上电保护约1s；离位稳定100ms触发警示及蜂鸣。首次按下旋钮或摇杆只消音，屏幕仍显示警告图案与“展品离位”，后续菜单、切图和调参恢复；归位稳定500ms解除并重新布防。恢复默认不清除实际离位状态。
