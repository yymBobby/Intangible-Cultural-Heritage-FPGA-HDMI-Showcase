# 资源镜像与编号

当前格式由 `03_Software/tools/c_phase2/multi_image.py` 的构建和检查函数定义，镜像标识为 `ICHSHOW3`。这是原始扇区镜像，不是普通文件系统。

| 区域 | 内容 |
|---|---|
| LBA 0 | 镜像头、格式及字库身份等信息 |
| LBA 1 | 4条主题记录，每条32 B |
| LBA 2 | 16条图片记录，每条32 B |
| LBA 3～2047 | 保留区 |
| LBA 2048起 | 按512 B边界分配的BMP、WAV和字幕数据 |

主题记录关联音乐与共享字幕，图片记录关联BMP位置、长度、主题内图号等信息。起始LBA按512 B计，文件长度按有效字节计；末扇区填充不属于有效载荷。构建器自动生成目录、地址和校验信息，并回读核对。

| 主题 | 主题号 | 四张图片ID | 音频ID | 字幕ID |
|---|---:|---|---|---|
| 京剧 | 0 | 0x00～0x03 | 0x40 | 0x80 |
| 醒狮 | 1 | 0x04～0x07 | 0x41 | 0x81 |
| 古琴 | 2 | 0x08～0x0B | 0x42 | 0x82 |
| 打铁花 | 3 | 0x0C～0x0F | 0x43 | 0x83 |

共24项资源。请求中的资源ID选择文件，块号表示文件内第几个512 B块，不能当成整卡绝对LBA。主题配置见 `04_Media/Pack_Input/themes.json`；实际地址和有效字节数见镜像manifest。

图片输入为640×480、24位无压缩BMP；音乐为48 kHz、16位双声道PCM WAV。字幕 `ICHTXT02` 保存字符编号，按配套 `glyph_map.json` 映射，不能把UTF-8文本直接作为上板字幕文件。现版字库ID `0xCBE17BCF`，普通字符0～174，警告图案175，物理容量192槽。

通用字体重新生成会改变字形内容和身份；替换字库时需同步ROM、编号表、字幕和镜像身份，不应只替换单个HEX文件。
